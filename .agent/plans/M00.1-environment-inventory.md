## Risks

- The apparent app-registration/site-installation split can cause an agent to run migrations or tests against the wrong assumption.
- Host Node `20.18.1` fails the frontend manifest's minimum version despite a passing type-check; host builds are not a supported baseline until corrected or explicitly accepted.
- Launching Frappe tests on the development site without an isolated test plan risks database changes.
- Directly coupling Service Hub to `itnovel_common` DocTypes would violate ADR-004 and can bypass the still-undecided permissions/provider boundary.
- Secret configuration exists in local devcontainer configuration. Any future setup documentation and CI output must continue to omit secret values.
